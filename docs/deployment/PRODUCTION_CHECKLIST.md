## 环境准备

### 系统要求
- [ ] Python 3.14+ 已安装并可用

- [ ] 最小2GB RAM可用
- [ ] 最小10GB磁盘空间可用
- [ ] 网络连接稳定（需访问API端点）

### 依赖安装
- [ ] 所有依赖已安装: `pip install -r requirements.txt`
- [ ] 验证关键包版本:
  - [ ] httpx >= 0.24.0
  - [ ] structlog >= 23.1.0
  - [ ] textual >= 0.41.0
  - [ ] pytest >= 7.4.0（开发环境）

## 性能验证

### 基准测试
- [ ] 运行性能测试: `pytest tests/benchmark/ -v`
- [ ] 单Agent响应 < 5秒
- [ ] 3个Agent并发响应 < 10秒
- [ ] Token追踪开销 < 5%
- [ ] 上下文隔离开销 < 3%
- [ ] MessageBus吞吐量 > 100 msg/s
- [ ] Session创建延迟 < 100ms

### 压力测试
- [ ] 运行压力测试: `pytest tests/stress/ -v`
- [ ] 网络超时自动重试3次
- [ ] API限流正确退避
- [ ] 并发Agent失败隔离正确
- [ ] 部分Agent失败不影响其他
- [ ] 100次迭代无内存泄漏（增长<10%）

### 内存检查
- [ ] 空闲状态内存使用 < 500MB
- [ ] 10个并发session内存使用 < 1GB
- [ ] 长时间运行（1小时）无内存泄漏

## 应急响应

### 常见故障及应对

**故障**: 应用无法启动
- [ ] 检查日志: `tail -100 logs/error.log`
- [ ] 检查Python版本: `python3 --version`
- [ ] 检查依赖完整性: `pip check`
- [ ] 尝试回滚到上一版本

**故障**: Agent响应超时
- [ ] 检查API密钥有效性
- [ ] 检查网络连接: `curl https://api.anthropic.com`
- [ ] 检查API配额是否耗尽
- [ ] 查看重试日志

**故障**: 内存不足
- [ ] 检查活跃session数量
- [ ] 清理旧session
- [ ] 重启应用
- [ ] 增加系统内存

**故障**: 日志磁盘满
- [ ] 清理旧日志: `find logs/ -mtime +7 -delete`
- [ ] 配置日志轮转
- [ ] 增加磁盘空间
